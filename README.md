# WEBSITE-DATA-SCRAPPING----PYTHON
Developed a Python-based web scraping solution using BeautifulSoup and Requests to extract stock data including prices, company details, and trading trends from financial websites. Cleaned and stored the data in structured formats such as CSV for analysis, demonstrating skills in data extraction, automation, and preprocessing.

Stock Market Web Scraping using Python
Project Overview

This project focuses on developing an automated web scraping solution using Python to extract structured stock market data from publicly available financial websites. The goal is to collect key financial metrics efficiently and store them in a structured format for analysis, eliminating the need for manual data collection.

Problem Statement

Financial stock data such as market price, market capitalization, profit growth, P/E ratio, dividend yield, and sales growth is essential for evaluating company performance and making informed investment decisions. However, manually gathering this data from multiple sources is time-consuming, inefficient, and prone to errors.
The objective of this project is to automate the extraction of relevant stock market data using Python web scraping techniques. The extracted data is cleaned, structured, and stored in CSV format, making it suitable for further financial analysis, visualization, and decision-making.


Tools and Technologies Used

Programming Language: Python

Libraries: BeautifulSoup, Requests, Pandas

Environment: Jupyter Notebook / VS Code

Data Storage: CSV file


Conclusion

The project successfully demonstrates the use of Python web scraping techniques to automate the extraction of stock market data. The structured dataset enables efficient analysis of company performance based on key financial indicators such as market price, growth metrics, and profitability.

The code for the web scrapping is available in the data.zip file.
